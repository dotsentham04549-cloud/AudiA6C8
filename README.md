# Склад разбора A6

Веб-приложение для разбора Audi A6 C8 (4K) 2020, 45 TFSI DLHA, VIN …032485.

- Поиск детали по номеру с наклейки (можно с пробелами и русскими буквами) или по названию.
- Каталог оригинальных номеров по VIN: 550 деталей, 823 номера; варианты одной детали собраны в одну строку.
- Рекомендованная цена — медиана объявлений Авито на 22.10.2026 (63 позиции), для остальных — оценка.
- Склад: артикулы A6-0001…, статусы «Снято / Выставлено / Продано / Брак», текст объявления для Авито, выгрузка CSV.
- Наклейки со штрихкодом: лента PNG шириной 48 мм для мини-термопринтера (рулон 57 мм) через «Поделиться», или PDF для принтера наклеек.
- Данные хранятся только в этом телефоне (память браузера). Делай резервную копию во вкладке «Итоги».
- Работает без интернета после первого открытия; можно добавить на главный экран.
